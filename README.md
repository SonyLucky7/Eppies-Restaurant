# Eppies Restaurant — Modern Digital Presence

A modern, clean, and interactive website for **Eppies Restaurant** — West Sacramento's beloved family dining landmark serving the community for over 40 years.

---

## 🍽️ About Eppies Restaurant

- **Location**: 4025 Lake Road, West Sacramento, CA
- **Phone**: (916) 371-7767
- **Hours**: Open Daily 7:00 AM – 8:30 PM
- **Heritage**: Family-owned and operated for over 40 years
- **Offerings**: Scratch-made Breakfast, Lunch & Dinner daily
- **Amenities**: Indoor Dining, Takeout, ADA Accessible, Large Free Parking Lot
- **Famous Specials**:
  - **Wednesday**: Homestyle Glazed Meatloaf
  - **Thursday**: Slow-Smoked BBQ Ribs
  - **Friday**: Hand-Carved Herb-Crusted Prime Rib

---

## ✨ Features & Architecture

- **Full-Covered 4K Cinematic Hero**: Full-bleed 4K culinary photography with interactive 3D multiplane parallax drift and discrete scene switcher.
- **Editorial Typography System**:
  - **Playfair Display**: Timeless serif headline typography.
  - **Lato**: Crisp, readable modern sans-serif body.
  - **JetBrains Mono**: Clean monospace numerals for pricing and operational metrics.
- **Bespoke Button Architecture**: Tailored `rounded-xl` geometry with single-line optical alignment and tactile micro-interactions.
- **Comprehensive Digital Menu (`/menu`)**:
  - Filter by meal type (Breakfast, Lunch, Dinner, Beverages, Desserts, Senior).
  - Searchable items with dietary and calorie details.
  - High-res modal detail views with ingredients and portion notes.
- **Weekly Specials Showcase**: Interactive day switcher exploring Wednesday Meatloaf, Thursday Ribs, and Friday Prime Rib.
- **Our Story (`/about`)**: Editorial timeline storytelling with the Four Pillars of Eppies and authentic community awards.
- **Location & Contact (`/location`, `/contact`)**: Interactive Google Maps embeds, amenities badges, and direct call/directions actions.

## 🚀 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Next.js Google Fonts (`Playfair Display`, `Lato`, `JetBrains Mono`)

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
